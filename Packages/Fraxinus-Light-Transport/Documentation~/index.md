# Fraxinus Light Transport

Contains shared code used for writing raytracing or pathtracing algorithms.

This independently maintained Unity 2022.3 backport is not an official Unity
release. Its tested path uses the RadeonRays Compute backend; Unity 6's native
APV integrator, hardware ray tracing and Embree paths are not provided on 2022.

Start with the [package README](../README.md) for installation and validation
scope, and [Unity 2022 compatibility](Unity2022-backport.md) for backend details.
